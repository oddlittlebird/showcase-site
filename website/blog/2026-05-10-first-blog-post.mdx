This site is launched!

I mean, it's been online for a while, but I feel like this blog post is what makes it complete.

You see, this post is what marks the beginning of the workflow testing.

Let me explain.

{/* truncate */}

A while ago, I realized that we documentarians need a way to demonstrate what we do, to really show our value. Unfortunately, a lot of our best stuff is frequently in company hands and hidden behind layers of NDAs. My solution?

Build it ourselves.

Hence, this showcase site was born. It's a proof of concept (POC) site that not only has the information about me that a hiring manager might want (resume, samples, and so on), it also has a GitHub repo showing a semi-automated documentation workflow.

GitHub actions, Doc Detective, agent skills, Vale, and so on. They're all here, and they will run on every page that I write and merge. This will allow me to test and improve the workflow over time.

And because the repo is public, potential employers can see the backend as well as the frontend.

Future blog posts will discuss more about the process and lessons I learn. But for now...launch!
