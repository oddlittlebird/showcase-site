# Documentation systems portfolio

This site demonstrates a documentation pipeline that enforces quality automatically and keeps content trustworthy over time.

The stack: **Vale** for style linting, **Doc Detective** for docs-as-tests, **pipeline.md** for agent-facing documentation, and **GitHub Actions** to wire it all together.

Browse the [Portfolio](/portfolio) to see writing samples, or read the [Blog](/blog) to see how this pipeline was built.
